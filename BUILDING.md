# Building Mull

```
npm install
npm start            # run from source
npm run pack         # unpacked app in dist/win-unpacked (fast, for testing)
npm run dist         # installer: dist/Mull-Setup-<version>.exe          (Vulkan + CPU, ~130 MB)
npm run dist:cuda    # installer: dist/Mull-Setup-<version>-NVIDIA.exe   (adds CUDA, ~380 MB)
```

The default installer runs on any GPU that supports Vulkan (NVIDIA, AMD, Intel) and falls back to CPU. The NVIDIA
build additionally bundles CUDA for the fastest speeds on GeForce cards.

After a fresh `npm install`, Electron's own binary may need fetching once:

```
node node_modules/electron/install.js
```

## Code signing (removes the Windows SmartScreen warning)

Mull builds unsigned by default. To sign, set these before running `npm run dist`; electron-builder picks them up:

```
set CSC_LINK=C:\path\to\certificate.pfx
set CSC_KEY_PASSWORD=your-password
```

A code-signing certificate is purchased from a certificate authority; it can't be generated by the build.

## Update notifications

Mull can tell users when a newer version exists but never installs anything by itself.
In **Settings → App & updates**, set *Update source* to either:

- a GitHub repository, e.g. `yourname/mull` (uses the latest GitHub release), or
- the URL of a JSON file: `{ "version": "1.3.0", "url": "https://example.com/download", "notes": "What's new" }`

## Where Mull keeps its data

`%APPDATA%\Mull` holds chats (`chats.json`), the model list (`models.json`), settings (`config.json`),
attached documents (`docs\`) and downloaded models (`models\`, or the folder you chose).
Uninstalling keeps this folder.

Data from the earlier "Local AI Chat" name is copied over automatically on first launch.
